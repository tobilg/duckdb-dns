# Contributing

Thanks for contributing to the DuckDB DNS extension! See the [README](README.md) for building and testing.

## Pull requests

1. Create a branch and open a pull request against `main`. Don't push directly to `main`.
2. Run the tests (`make test_debug`) and mention in the PR what you tested, including the DuckDB version.
3. Request a review from the other maintainer:
   - PRs by @onnimonni → request review from @tobilg
   - PRs by @tobilg → request review from @onnimonni
   - PRs by other contributors → either maintainer
4. A pull request is merged only after at least one approving review from someone other than its author.

`CODEOWNERS` requests a review from the maintainers automatically.
